# The Idea Factorium

A creative project hub — one place for all the stories, apps, art concepts, and wild ideas
that are currently scattered across a dozen AI chats.

## How This Is Organized

Each category has its own folder. Projects live as markdown files inside their category.

| Folder | What goes here |
|--------|---------------|
| `anime/` | Anime & animation series concepts |
| `webcomics/` | Webcomic ideas and storylines |
| `games-apps/` | Game concepts, app ideas |
| `film-tv/` | Film, TV, and live-action pitches |
| `novels-writing/` | Novels, short stories, writing techniques |
| `visual-art/` | Visual art projects, short films |
| `card-games/` | TCG mechanics, card game designs |
| `other/` | Anything that doesn't fit above |

## Project File Format

Each project is a single markdown file. Use `_PROJECT_TEMPLATE.md` as a starting point.

The basics:
- **One file per project** — name it something recognizable (e.g., `shadow-runners.md`)
- **Status tags** at the top so you can see what's active vs. just an idea
- **Keep it loose** — these are creative ideas, not spec docs. Capture the spark.

## Status Tags

Use these in project files to track where things stand:

- `idea` — Just a concept, hasn't been developed yet
- `exploring` — Actively thinking about it, fleshing things out
- `in-progress` — Actually building/writing/creating it
- `on-hold` — Parked for now, might come back to it
- `done` — Shipped, finished, or fully realized
