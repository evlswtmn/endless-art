# Dune's Forgotten Oasis

**Status:** `idea`
**Type:** novel
**One-liner:** An offshoot Arrakis colony develops eco-tech to terraform mini-oases using genetically modded sandworms.

## The Concept

A fanfic-style sequel set in the Dune universe. An offshoot colony on Arrakis develops
eco-tech to terraform mini-oases using genetically modded sandworms. The hero is a quirky
trader with a Piers Anthony-style pun habit.

Pitched as a short story series for newsletters or fan sites, with potential for a
serialized Wattpad/Patreon run.

## Key Elements

- Dune universe setting (fanfic — IP considerations apply)
- Eco-terraforming as central plot mechanic
- Genetically modified sandworms with "attitude problems"
- Quirky trader protagonist — lighter tone than Herbert
- Piers Anthony-style wordplay and puns woven through
- Herbert's worldbuilding depth meets comedic character work

## Inspiration / References

- Frank Herbert's Dune series (the world)
- Piers Anthony (pun-driven humor style)
- Eco-fiction / solarpunk (terraforming optimism)
- The Expanse (frontier colony politics)
