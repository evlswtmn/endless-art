# Token-Based Distributed LLM

**Status:** `idea`
**Type:** app
**One-liner:** Open-source community app where users share GPU resources to collectively run a large LLM, with crypto-style token rewards.

## The Concept

An open-source community app where users share GPU resources to collectively run a large
LLM locally, split across machines. Includes a token/award system similar to crypto mining
to incentivize participation.

Democratizing AI compute — you don't need a data center if enough people share GPUs.

## Key Elements

- Distributed computing for LLM inference
- Community-contributed GPU resources
- Token/reward system incentivizing participation (like crypto mining)
- Open-source codebase
- Local-first — no data sent to corporate servers
- Could run models too large for any single machine

## Inspiration / References

- BOINC / Folding@Home (distributed computing for science)
- Crypto mining (incentive model)
- Petals (existing distributed LLM project)
- BitTorrent (peer-to-peer resource sharing)
