# Rampage Drop / Tetris Meets Angry Birds

**Status:** `idea`
**Type:** game
**One-liner:** Drop characters onto structures to destroy them — block-dropping meets physics destruction with a wealth redistribution narrative.

## The Concept

Two related game concepts that evolved together:

### Tetris Meets Angry Birds
A mobile game combining block-dropping mechanics with physics-based destruction. Players
strategically drop tetromino blocks onto structures to destroy them. Incorporates common
elements from top mobile games.

### Rampage Drop
A destruction-based mobile game where you drop characters or objects onto wealthy
neighborhoods/corporate buildings, causing chaos and "redistributing" resources. Has both
gameplay and narrative elements about economic inequality.

## Key Elements

- Block-dropping + physics destruction hybrid
- Satisfying destruction mechanics (the core fun)
- Tetromino shapes add strategic element to the dropping
- Narrative layer about economic inequality (optional — could be pure arcade)
- Mobile-first design
- Simple to learn, deep to master
- Potential for level design around real-world-inspired structures
