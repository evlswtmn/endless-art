# TCG Arena Spectator Mode

**Status:** `idea`
**Type:** app
**One-liner:** A dedicated spectator client for digital card games that makes watching TCGs feel like watching real sports.

## The Concept

A feature concept for existing digital card games (like MTG Arena). A dedicated spectator
client that allows viewers to see both players' hands simultaneously — like traditional
sports broadcasting — with enhanced UI, live commentary tools, and deep stats.

Designed to bridge the gap between playing card games and actually enjoying them as an esport.

## Key Elements

- Dual-hand visibility (see both players' cards like a poker broadcast)
- Enhanced spectator UI — not just the player UI with stuff hidden
- Live commentary tools (telestrator, card highlights, play prediction)
- Deep stats overlay (win probability, mana curve analysis, etc.)
- Designed for streaming/broadcast, not just casual spectating

## Inspiration / References

- ESPN/sports broadcasting UI design
- Poker broadcasts (showing both hands)
- League of Legends spectator mode / observer tools
- Chess.com live analysis board
