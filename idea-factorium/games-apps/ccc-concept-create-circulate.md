# CC&C (Concept - Create - Circulate)

**Status:** `idea`
**Type:** app
**One-liner:** Friends chat, tag messages as "ideas," AI turns those ideas into content drafts — scripts, tweet threads, hooks.

## The Concept

A web app where friends chat casually, tag certain messages as "ideas," and AI turns those
tagged ideas into content drafts — scripts, tweet threads, hooks, and more. Think group
chat meets content factory.

## Key Elements

- Group chat interface (the social layer)
- "Idea tagging" — flag any message as a seed for content
- AI content generation from tagged ideas
- Output formats: scripts, tweet threads, hooks, blog drafts
- React frontend + Node backend (scaffolded)
- Future: analytics, social posting, mobile apps

## Technical Stack (Explored)

- React frontend
- Node.js backend
- Idea tagging system in chat
- AI integration for content generation
- Future: analytics dashboard, direct social media posting, mobile apps

## Inspiration / References

- Slack/Discord (group chat as idea capture)
- Notion AI (turning notes into content)
- Jasper/Copy.ai (AI content generation)
- The natural way ideas come up in conversation
