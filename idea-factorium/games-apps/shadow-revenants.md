# Shadow Revenants

**Status:** `idea`
**Type:** game
**One-liner:** Retro 2D browser game — ninja meets undead horror, built with HTML5 Canvas in under 500 lines.

## The Concept

A retro-style 2D browser game with a ninja + undead horror vibe. Built with HTML5 Canvas
and vanilla JavaScript, designed to be under ~500 lines of code and extensible for more
levels, monetization, and custom art/audio.

## Key Elements

- HTML5 Canvas + vanilla JS (no framework overhead)
- Retro 2D aesthetic
- Ninja protagonist vs. undead enemies
- Horror atmosphere
- Under ~500 lines of core code (lean and extensible)
- Browser-based — zero install, play anywhere
- Designed for extensibility: more levels, art, audio

## Technical Details

- Canvas element + UI div + script tags + minimal styling
- This HTML structure serves as a base for other game experiments
- Can be extended with custom art and audio assets
