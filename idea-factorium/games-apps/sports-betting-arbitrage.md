# Sports Betting Odds Arbitrage Dashboard

**Status:** `idea`
**Type:** app
**One-liner:** A Streamlit dashboard detecting arbitrage opportunities across bookmakers for guaranteed profit windows.

## The Concept

A Streamlit dashboard using The Odds API to detect arbitrage opportunities across multiple
bookmakers. Calculates guaranteed profit percentages and compares odds in real-time.

A v1 was already built and debugged (v1→v4 API endpoint migration, arbitrage detection
logic fixes).

## Key Elements

- Streamlit-based dashboard (Python)
- The Odds API integration (v4)
- Multi-bookmaker odds comparison
- Arbitrage opportunity detection and profit calculation
- Real-time data refresh
- Already has working prototype (debugged in Kimi chat)

## Inspiration / References

- Sports betting arbitrage strategy
- Existing arb calculators (but most are paid/limited)
- Streamlit for rapid dashboard prototyping
