# Interactive 3D Gallery

**Status:** `idea`
**Type:** visual-art
**One-liner:** An HTML webpage with a rolling 3D gallery — background blur, slow rotation, interactive hover states.

## The Concept

An HTML webpage featuring a rolling gallery of products or art with 3D interactive elements.
Background blur effects for visual depth, slow rotation animations, and interactive hover
states.

Could be directly related to the endless-art project.

## Key Elements

- 3D interactive gallery in the browser
- Rolling/carousel display
- Background blur for depth of field effect
- Slow rotation animations
- Interactive hover states
- Products or art as content
- Pure HTML/CSS/JS — no heavy frameworks needed

## Inspiration / References

- CSS 3D transforms and perspective
- Apple product pages (scroll-driven 3D reveals)
- Three.js galleries
- The endless-art project concept
